# Asset Manifest

This game ships no third-party art, audio, font or level assets. The galaxy and fleets are
generated at run time, and the cockpit in `voidfarer/static/` is HTML, CSS and JavaScript source
code licensed under AGL-1.1. No asset is extracted or redistributed.

|---|---|---|---|---|

| `assets/screenshots/**` | captured UI screenshots | AegeanWorks | AGL-1.1 | scripted `ui_browser` captures, commit-stamped in `.aikit/media.json` |
